# Проект "EBAC" – Одностраничный лендинг

## О проекте

**EBAC** — это одностраничный лендинг, разработанный для компании EBAC. Лендинг включает в себя анимации, CSS-маски, адаптивную верстку, "липкий" хедер, а также валидацию форм в секциях subscribe и footer. В проекте реализована оптимизация изображений, а для именования классов использована методология БЭМ, и схема организации CSS-блоков — Nested.

Проект был выполнен в рамках задания №1 стажировки компании DIGITAL SECTOR.

## Функциональность

- **Анимации и CSS-маски**: Использованы для улучшения визуальных эффектов.
- **Адаптивность**: Сайт корректно отображается на различных устройствах.
- **Липкий хедер**: Заголовок остаётся на месте при прокрутке страницы.
- **Валидация форм**: Формы в секциях subscribe и footer содержат валидацию для корректности введённых данных.
- **Оптимизация изображений**: Все изображения оптимизированы для быстрой загрузки.

## Технологии и инструменты

- **HTML5** — Семантическая структура страницы.
- **CSS3** — Стилизация с использованием медиа-запросов и анимаций.
- **JavaScript** — Логика взаимодействия с формами.
- **БЭМ** — Методология организации CSS-классов.
- **WebP** — Формат изображений для улучшенной производительности.

## Запуск проекта

1. Клонируйте репозиторий:

   ```bash
   git clone https://github.com/kirill-io/EBAC-project.git
   ```

2. Перейдите в директорию проекта:

   ```bash
   cd ebac-project
   ```

3. Установите зависимости:

   ```bash
   npm install
   ```

4. Запустите проект в режиме разработки:

   ```bash
   npm run start
   ```

5. Для сборки проекта:

  - Режим разработки:

    ```bash
    npm run build:dev
    ```

  - Production-сборка:
  
    ```bash
    npm run build:prod
    ```
